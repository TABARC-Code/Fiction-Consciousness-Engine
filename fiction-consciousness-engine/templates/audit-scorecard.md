# Audit scorecard

Use ONLY when the user explicitly asks to see the audit. By default, scores stay silent and the output is the revised scene alone.

Anchors: 5 invisible craft. 4 sound, leave alone. 3 visible seam, revise. 2 repeated or structural failure. 1 absent or contradicted.

| # | Category | Score | Close-reading note (what you actually saw) |
|---|---|---|---|
| 1 | Character-specific narrative voice | | |
| 2 | Natural free indirect discourse | | |
| 3 | Believable internal reasoning | | |
| 4 | Organic exposition and background integration | | |
| 5 | Realistic character-specific dialogue | | |
| 6 | Concrete physical and technical credibility | | |
| 7 | Associative memory and psychological depth | | |
| 8 | Organic sentence and paragraph rhythm | | |
| 9 | Appropriate suspense and emotional escalation | | |
| 10 | Continuity and causal plausibility | | |

Notes are about specific passages. Counting devices is not a note.

## Revisions made

For each category below 4: which passage, what was wrong, what changed. State what was preserved (events, facts, dialogue intent, characterisation).

## Left alone

Passages that were effective and untouched.

## Still uncertain

Anything the close reading could not settle. Say so rather than scoring on a guess.

## Judge calibration (run before a project, and after any anchor change)

| Passage | Type (approved / rejected) | Lowest category score | Categories at 3 or below | Author's own read agrees? |
|---|---|---|---|---|
| | | | | |

Approved passages should mostly score 4 or 5. Rejected passages should show at least one category at 3 or below. Target: auditor and author disagree on no more than one passage in four. Disagreements are logged in `kaizen-log.md`.
