# Style profile

Internal. Built from approved material through `references/06`, and tested by the clone and rebuild checks before it is relied on. Describes craft behaviour. Never copies wording, characters, technologies or plot elements from any source. Write "unclear" where evidence is thin. A blank is better than a guess. A wrong entry is worse than a missing one, because later chapters will bend to fit it.

The same content lives in `style-profile.json`. Keep the two matched. If they differ, the Markdown version is the one the author last approved.

## Tier key

A1 quoted and located. A2 paraphrased behaviour, located. A3 worked example. A4 inferred, never used to write prose until confirmed. Confidence is separate: high, medium or low.
